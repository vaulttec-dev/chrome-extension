# Диктофон → буфер

Окреме Chrome-розширення (Manifest V3). Керується гарячою клавішею або кнопкою 🎤 у
вікні розширення:

1. **Alt+Shift+D** — почався запис із мікрофона (на іконці бейдж **REC**).
2. **Alt+Shift+D** ще раз — запис зупиняється, Gemini розшифровує (бейдж **…**), текст
   потрапляє в буфер обміну, приходить нотифікація «Скопійовано N симв.». Вставляйте Ctrl+V.

Клавішу можна змінити або зробити **глобальною** (працюватиме, навіть коли Chrome не у
фокусі) на `chrome://extensions/shortcuts`.

## Встановлення
1. `chrome://extensions` → **Режим розробника** → **Завантажити розпаковане** → тека `dictaphone/`.
2. Клік по іконці → вставте **Gemini API-ключ** ([aistudio.google.com/apikey](https://aistudio.google.com/apikey)) → «Зберегти ключ».
3. Перше натискання клавіші відкриє вкладку з запитом дозволу на мікрофон — дозвольте один раз.

## Файли
| Файл | Роль |
|------|------|
| `manifest.json` | Дозволи (`storage`, `offscreen`, `clipboardWrite`, `notifications`), гаряча клавіша (`commands`). |
| `background.js` | Обробка клавіші й кнопки, бейдж, нотифікації, стан для попапа, керування offscreen-документом. |
| `offscreen.html` / `offscreen.js` | Невидимий документ: тримає мікрофон, пише аудіо, транскрибує, копіює текст у буфер. |
| `gemini.js` | Транскрипція: Files API → `gemini-3.5-transcribe` (запасний шлях — `gemini-flash-latest`). |
| `popup.html` / `popup.js` | Кнопка 🎤 зі станом запису, гаряча клавіша, Gemini-ключ. |
| `mic.html` / `mic.js` | Одноразовий запит дозволу мікрофона. |
